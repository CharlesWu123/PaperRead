# 《Video-As-Prompt: Unified Semantic Control for Video Generation》阅读报告

## 论文基本信息

标题：Video-As-Prompt: Unified Semantic Control for Video Generation  
作者：Yuxuan Bian, Xin Chen, Zenan Li, Tiancheng Zhi, Shen Sang, Linjie Luo, Qiang Xu  
机构：The Chinese University of Hong Kong；ByteDance  
方向：可控视频生成、视频扩散模型、语义控制、in-context generation  
论文链接：arXiv:2510.20888v1  
项目页：https://bytedance.github.io/Video-As-Prompt  
代码状态：项目页和 GitHub 仓库已公开，但本地网络不支持 clone；本报告仅基于论文正文、arXiv HTML、项目页和已公开摘要信息整理。

## 一句话总结

这篇论文提出 Video-As-Prompt（VAP）：把“参考视频”直接当作语义提示词，让视频生成模型像理解上下文一样，从参考视频中提取动作、风格、概念变化、镜头运动等抽象语义，并迁移到新的输入图像/文本生成任务中，从而实现统一、可泛化的语义可控视频生成。

## 核心问题

现有可控视频生成方法大致有两类问题。

第一类是结构控制方法，比如 depth、pose、optical flow、edge、mask 等。这些方法的优势是控制信号明确，但问题是它们往往带有强像素级或几何级先验。也就是说，模型不仅学“这个视频应该有类似动作/风格”，还会被迫对齐具体的空间结构、局部纹理或运动轨迹。对于“变成玩具”“变成漫画风”“被液态金属覆盖”“主体飞起”等抽象语义，这种像素级控制反而会成为负担。

第二类是任务特定或条件特定的方法。例如某个模型专门做动作迁移，另一个模型专门做风格化，再另一个模型专门处理镜头控制。这类方法通常需要为每种条件设计专门结构、专门训练数据或专门微调，泛化能力差，也很难统一扩展到新的语义类型。

VAP 的切入点是：既然很多语义很难用文本或显式结构图表达，那能不能直接让参考视频作为“提示词”？例如用户给一段“人物变成 Simpson 风格动画”的参考视频，再给一张新人物图，模型就生成“这个新人物也发生类似风格转化”的视频。

## 方法核心

VAP 的关键思想是：

> Treating reference videos as in-context prompts.

也就是把参考视频作为上下文，而不是把它解析成某种固定控制格式。模型需要从参考视频中抽取“语义规律”，再应用到目标生成视频上。

整体输入可以理解为三部分：

1. 目标图像或目标条件：要被生成/编辑的主体。
2. 文本 prompt：描述目标主体或补充细节。
3. 参考视频 prompt：携带希望迁移的语义，比如动作、风格、概念转化、相机运动。

输出是一个新视频，它保留目标主体身份或目标图像内容，同时复用参考视频中的抽象语义模式。

## Mixture-of-Transformers 架构

论文没有直接全量微调原始视频扩散 Transformer，而是提出一种 plug-and-play 的 Mixture-of-Transformers（MoT）结构。

核心原因是：如果直接在有限的 VAP 数据上微调大型视频生成基座，容易出现 catastrophic forgetting，也就是模型忘掉原来强大的图像/视频生成能力。为了避免这一点，VAP 保持原始 Video Diffusion Transformer（DiT）冻结，同时增加一个可训练的 in-context expert transformer。

可以把它理解成：

- 冻结主干 DiT：负责维持原模型的视频生成能力。
- 可训练专家 Transformer：负责理解参考视频 prompt 中的语义。
- 两者在 Transformer 层中通过 attention 交互，让生成 tokens 能够读取参考视频 tokens 中的语义信息。

这样做的好处是，VAP 不需要为每一种语义条件单独设计模型结构。参考视频就是统一接口。无论是概念变化、风格迁移、动作迁移，还是镜头运动，都可以通过同一种“视频作为 prompt”的形式进入模型。

## 位置编码设计

论文特别强调了 position embedding 的问题。参考视频和目标视频不是逐像素、逐帧对应关系。如果直接让它们共享完全相同的位置编码，模型可能会误以为参考视频的某个空间位置、某个时间点应该和目标视频严格对齐。

这会引入错误的 pixel-level spatiotemporal mapping prior。换句话说，模型会错误地把“参考视频作为语义提示”理解成“参考视频作为像素模板”。

VAP 的解决方式是对参考视频 prompt 的时间索引做固定偏移，让参考视频 token 在时间维度上位于目标 noisy video token 之前，同时保留空间索引。论文称这种 temporally biased position embedding 能减少虚假的像素级映射先验，更符合 in-context generation 的顺序建模逻辑。

实验中，这个设计比 identical position embedding 表现更好。论文消融表显示：

| 位置编码设计 | Visual Quality | Text Alignment | Semantic Alignment | Motion Quality | Overall |
|---|---:|---:|---:|---:|---:|
| Identical PE | 23.17 | 98.49 | 70.83 | 57.09 | 68.98 |
| Negative shift in T/W/H | 23.45 | 98.53 | 72.92 | 57.31 | 69.05 |
| VAP 最终方案 | 24.13 | 98.59 | 77.08 | 57.71 | 70.44 |

这里最关键的是 Semantic Alignment，从 70.83 提升到 77.08，说明位置编码不是小细节，而是直接影响模型能否把参考视频理解成“语义提示”。

## VAP-Data 数据集

为了训练这种统一视频 prompt 范式，作者构建了 VAP-Data。论文称这是目前最大的 semantic-controlled video generation 数据集，包含超过 100K curated paired samples，覆盖 100 个语义条件。

数据来源大致是：

- 收集约 2K 高质量参考图像；
- 使用商业模型的视频特效模板、社区 LoRA 等生成成对视频；
- 将同一类语义条件组织成参考视频和目标视频配对；
- 覆盖概念、风格、动作、镜头等多个大类。

论文列出的主要类别包括：

| 一级类别 | 子类型举例 | 数据规模 |
|---|---|---:|
| Concept | entity transformation、entity interaction | 数万级 |
| Style | cartoon、ghibli、simpsons、painting 等 | 约 15K |
| Motion | human motion、non-human motion | 数万级 |
| Camera | 运镜、镜头变化 | 若干类别 |

这个数据集的重要性在于，它不是只训练某一个特效，而是把许多不同语义控制都统一成“参考视频 prompt -> 目标视频”的学习问题。

## 实验设置

论文主要比较了 VAP 和以下几类方法：

1. VACE 系列，包括 original、depth、optical flow 等结构控制版本。
2. CogVideoX-I2V 及其 LoRA 版本。
3. 商业模型 Kling / Vidu。
4. VAP 自身。

评估指标包括：

- Visual Quality：视频视觉质量。
- Text Alignment：文本一致性。
- Semantic Alignment：生成视频与参考视频语义的一致性，使用 Gemini-2.5-Pro / GPT-5 等模型辅助评分。
- Motion Quality：运动质量。
- Overall：综合分。
- Preference Rate：人工偏好率。

## 主要结果

论文主表中，VAP 在开放模型中达到最强，并且接近商业模型 Kling / Vidu。

| 方法 | Alignment Score Gemini-2.5-Pro ↑ | Alignment Score GPT-5 ↑ | Preference Rate ↑ |
|---|---:|---:|---:|
| VACE Original | 35.38 | 32.52 | 0.6% |
| VACE Depth | 43.35 | 39.41 | 0.7% |
| VACE Optical Flow | 46.71 | 45.09 | 1.8% |
| CogVideoX-I2V | 26.04 | 28.36 | 6.9% |
| CogVideoX-I2V LoRA | 68.60 | 66.93 | 13.1% |
| Kling / Vidu | 74.02 | 73.91 | 38.2% |
| VAP | 70.44 | 70.26 | 38.7% |

这个结果有两个重点。

第一，VAP 显著优于传统结构控制方案。Depth / Optical Flow 这类方法在局部运动或结构约束上有用，但面对抽象语义迁移时不够自然。VAP 的 semantic alignment 明显更高，说明“视频作为语义 prompt”比“结构图作为控制条件”更适合复杂概念和效果迁移。

第二，VAP 的人工偏好率达到 38.7%，略高于 Kling / Vidu 的 38.2%。这并不意味着 VAP 全面超过商业模型，但说明在论文设定的语义控制任务中，VAP 已经具备接近商业模型的可用质量。

## 可扩展性实验

论文还做了训练数据规模消融：

| 训练规模 | Visual Quality | Text Alignment | Semantic Alignment | Motion Quality | Overall |
|---|---:|---:|---:|---:|---:|
| 1K | 22.84 | 92.12 | 60.42 | 56.77 | 63.91 |
| 10K | 22.87 | 94.89 | 64.58 | 56.79 | 66.28 |
| 50K | 23.29 | 96.72 | 70.83 | 56.82 | 68.23 |
| 100K | 24.13 | 98.59 | 77.08 | 57.71 | 70.44 |

这个表很关键。随着数据从 1K 增加到 100K，Semantic Alignment 从 60.42 提升到 77.08，Overall 从 63.91 提升到 70.44。说明 VAP 不是只靠架构 trick，而是很依赖大规模、多语义的数据覆盖。换句话说，“video-as-prompt”这个范式有明显 scaling potential。

## 零样本能力

VAP 的另一个重要贡献是 zero-shot generation。论文中提到，当给定训练集中没有出现过的参考语义，例如 crumble、dissolve、levitate、melt 等，VAP 仍然能根据参考视频生成对应语义的视频。

这说明模型没有简单记住某个固定特效类别，而是在一定程度上学会了“从参考视频中抽取可迁移语义”。这是 VAP 相比条件专用模型最有价值的地方。

不过这里也要谨慎：论文展示的是若干 qualitative cases 和 benchmark 结果，不能直接推断它对任意复杂现实视频都能稳定泛化。它的泛化仍然会受参考视频质量、语义清晰度、目标主体类型和训练分布影响。

## 下游应用

项目页展示了 VAP 可以支持几类使用方式：

1. 不同语义参考视频 + 同一目标图像：让同一个主体执行不同语义效果，例如变漫画、变玩具、飞起、旋转等。
2. 同一语义的不同参考视频 + 同一目标图像：用不同参考视频表达同一类语义，测试模型对语义而非具体像素的理解。
3. 同一参考视频 + 不同目标图像：把同一种语义迁移到不同人物、动物、物体或场景上。
4. 同一参考视频和图像 + 用户修改 prompt：在保持参考语义和主体身份的同时，用文本调整细节。

这使 VAP 更像一个“视频效果克隆器”或“视频语义迁移器”，而不只是传统 image-to-video 模型。

## 论文贡献

我认为这篇论文的贡献可以概括为三点。

第一，提出了一个清晰的新范式：Video-As-Prompt。它把参考视频从“训练数据样本”变成“推理时的控制接口”，让视频生成控制从显式结构约束转向上下文语义学习。

第二，提出了适合该范式的 MoT 架构。冻结原始 DiT、添加可训练专家，既保留基座模型生成能力，又让模型学习参考视频语义控制，避免全量微调带来的灾难性遗忘。

第三，构建了 VAP-Data。超过 100K 配对视频、100 个语义条件的数据集为统一语义控制提供了训练基础，也解释了为什么 VAP 有较强的扩展性和零样本表现。

## 局限性

论文自身也提到，VAP-Data 虽然规模很大，但语义覆盖仍有限。100 个 semantic conditions 对研究来说已经很大，但对真实创作世界来说远远不完整。复杂交互、长时序剧情、多主体因果关系、精细物理过程等，可能仍然超出当前 VAP 的能力边界。

第二，VAP 对参考视频质量很敏感。如果参考视频中的语义不清晰、主体变化混乱、运动不稳定，模型可能难以抽取正确语义。它依赖的是“参考视频作为上下文”的能力，因此 prompt 本身质量会直接影响输出。

第三，语义迁移和身份保持之间存在张力。例如强风格化、强形变、主体变身类任务中，模型既要保持目标主体身份，又要遵循参考视频变化。两者冲突时，可能出现身份漂移、局部伪影、变化不完整或运动断裂。

第四，评价方法仍有争议。论文使用 Gemini-2.5-Pro、GPT-5 等模型做 semantic alignment 评分，并结合人工偏好。这个方向很实际，但 VLM-as-judge 对视频细节、时间连续性和复杂语义转移的判断是否稳定，仍需要进一步验证。

## 和视频编辑/可控生成的关系

如果从“视频编辑”角度看，VAP 最值得关注的不是它能生成某几个酷炫效果，而是它改变了控制接口。

传统视频编辑常见接口是：

- 文本：描述想要的变化；
- mask：指定编辑区域；
- depth/pose/flow：指定结构或运动；
- reference image：指定风格、身份或外观。

VAP 增加了一种更自然的接口：

- reference video：指定一段动态语义。

这对于视频编辑非常重要。很多视频需求本来就难用文字描述，比如“像这个视频一样从真人逐渐变成黏土动画”“像这个参考一样镜头绕主体旋转并拉近”“像这个特效一样被金属液体覆盖”。用视频作为 prompt，比写长文本更直观，也更容易让模型捕捉时间过程。

## 我的判断

这篇论文的价值不在于单个模型指标，而在于提出了一个很可能继续扩展的交互范式。未来的视频生成控制不一定只靠文本，也不一定靠手工标注的结构条件，而可能更多转向“示例即控制”：给模型一个视频示例，它从中理解你想要的动态语义。

VAP 目前仍然偏研究原型，受限于数据覆盖、参考视频质量、评估可靠性和复杂场景泛化。但它证明了一件事：参考视频可以成为视频生成模型的通用控制语言。这一点对后续视频编辑、短视频特效迁移、商品视频生成、角色动作复用和风格化生成都有直接启发。

## 结论

Video-As-Prompt 是一篇方向感很强的论文。它没有继续堆更多显式控制条件，而是把“参考视频”提升为统一语义控制接口：用户不必精确定义控制信号，只需要给一个包含目标语义的动态例子。模型通过 MoT 架构和 VAP-Data 学习从这个例子中抽取可迁移语义，再应用到新的生成目标中。

简而言之，这篇论文的核心启发是：

**当文本说不清一个视频效果时，最好的 prompt 可能就是另一个视频。**
