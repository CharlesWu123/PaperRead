# 通俗版 · Aspire：只说「变得更强」，不给考卷，模型能自己学吗？

> 只给一句「提升科学推理能力」，评测题全程保密：55 次自主训练只有 1 次留下高于底座的成果，最强的自生成 agent 外壳也输给了人写的参考实现。

## 一分钟版本

- 别的自进化论文都先把「考什么」告诉模型；这篇偏偏不给——只给一句宽泛目标，比如「提升数学推理能力」，具体考题 520 道全部保密。
- 模型要自己决定：学什么、拿什么数据学、怎么训练、怎么验证自己有没有进步。这四件事以前都是人替它做好的。
- 两个演化面：一个改模型权重（真的去微调），一个改 agent 外壳（提示词、工具、工作流，模型权重冻结）。
- 结论基本是负的：24 次「盲考式」训练只有 3 次超过底座；带稀疏反馈的 30 次搜索只有 1 次把成果留到最后；外壳演化最好的产物比原版 Qwen-Agent 还低 1.42 分。
- 论文最值钱的一句话：进步要跟起点比，别跟上一步比——关上了训练循环，不等于关上了能力循环。

## 先搞清楚三个概念

**宽泛目标（vague goal）。** 就像教练只说「这学期变强」，不说考什么。现有的自进化研究都是「这学期把三千米跑进 12 分钟」——目标清楚，只是让你自己想办法。Aspire 问的是前一种：连终点都要自己猜。

**代理验证（proxy validation）。** 摸不着真考卷，模型只能自己出练习题、自己打分。问题是自己出的题永远顺着自己的习惯——就像只练自己擅长的题型还给自己打满分。论文里有个活例子：一个模型用一道题上的 8 项检查清单从 7 分改到 8 分，就停手了，以为大功告成。

**隐藏评测（hidden eval）。** 520 道专家从零写的题，按六个目标分组锁在控制器那边。模型永远看不到题目、答案、评分标准。有的实验里模型能查到总分（只有总分，没有逐题反馈），有的实验里连总分都要交卷后才知道。

一句话串起来：**目标靠猜，验证靠自编，真考卷永远看不见**——这就是 Aspire 给模型设的局。

## 它想解决什么问题

开头举的例子很直白：一个想成为更好物理学家的人，要自己挑教材、找练习、发现知识缺口、判断自己是不是真有进步。自主学习其实是三个绑在一起的决定：**改什么、怎么改、怎么验证改好了**。

现在的 LLM 自进化研究（自己给自己出题、自己给自己当裁判、自己改自己的提示词）看起来很自主，但第一个决定——改什么——一直是人替模型做掉的：benchmark 名字写着呢，优化它就行。这把「自进化」降级成了「优化一个别人给的目标」。

Aspire 把第一个决定也交给模型，然后测三件事：

- RQ1：把明确任务换成宽泛目标，结果会差多少？（对照组：PostTrainBench 的官方成绩）
- RQ2：模型能不能靠微调自己的权重，把宽泛目标变成真实的能力提升？
- RQ3：权重不动，模型能不能改好自己的 agent 外壳（harness）？

## 核心思路：一个只能「点菜」的实验台

Aspire 不是提出更强的自进化方法，而是一台测谎仪。三个研究问题是一步步收紧的：先只换目标看差多少（对照组：PostTrainBench 官方成绩），再让模型全自主地改自己权重，最后连权重都不许动、只许改外壳。设计要点：

**模型不碰底层。** 不能开 shell、不能下载训练仓库、不能自己搭环境。只有一个工具接口，能做的动作是七类语义操作：注册数据、发起训练、验证、自评、评测、分支、终止。模型点菜，控制器做菜——每个请求都先验证再执行，非法请求直接打回，不产生任何东西。

**信息边界是铁的。** 模型看得见：目标那句话、自己找的公开数据、自己造的验证集。看不见：520 道题、参考答案、评分规则。每次注册训练数据，都要先过一道和隐藏题库的重叠检查（精确匹配 + 语义匹配），命中就拒收。实验配置还绑定 prompt 的 SHA-256 哈希，防止跑一半偷偷换题。

**打分只有总分。** 带反馈的实验里，模型能在限额内反复查某个目标的总分，但看不到任何一道题——论文管这叫「稀疏的黑盒结果通道」。不带反馈的实验里，40 个 GPU 小时随你训练，最后只能交一个终检模型，交之前一分都拿不到。

**安全回滚是协议内置的。** 候选分四层记账：拿到分的、符合资格的、被选中的、最终保留的。**只有被选中的那个分数超过底座模型，才真的保留；否则控制器直接回滚到底座。** 所以论文里任何「正结果」都天生保守——分数非负可能是回滚兜的底，不是学出来的。

**账本可查但查不到题。** 整个过程留下可携带的轨迹档案：只有计数、时间戳、源码哈希、资源消耗、提交和选择记录，不含题目、模型原始消息、逐题判分理由。事后能审计「它探索了什么、选了什么、回滚了几次」，但审计者自己也看不到题。

## 跑出来的效果

**RQ1：目标变模糊，总分掉 6 分左右。** 同样的训练接口、同样的评分器，只把「优化 HealthBench」换成「提升健康推理能力」这类宽泛说法。加权平均：Claude Opus 4.8 从官方的 32.90 掉到 27.07，GPT-5.6 从 36.23 掉到 29.58。不是全面变差——HumanEval、BFCL、GSM8K 上模糊目标反而更高，但 HealthBench 从 31.68 掉到 12.62 最惨。过程上有个有意思的发现：模糊目标的模型多花 2,109 秒思考、访问任务材料和自建评测脚本的密度变成 2.98 倍和 2.39 倍——精力确实转向了「搞清楚要学什么」。

**RQ2 盲考模式：24 次交卷只有 3 次超过底座。** Qwen3.5-4B 和 9B 各自优化六个目标、各跑两轮。12 个「模型×目标」组合里只有 1 个组合两次都超底座（9B 科学推理，45.33 → 48.00，涨 2.67 分）。六个目标平均分：4B 从 35.74 掉到 18.61，9B 从 39.01 掉到 25.64。最吓人的是 4B 科学推理：底座 44 分，两次交卷都是 0 分——模型自己挑的数据和训练方法直接把能力训没了。

**RQ2 带反馈模式：30 格搜索只有 1 次留到最后。** 五种配置（两个 Qwen 自导 + 三个 GPT-5.6 外脑）× 六个目标。28 格至少训出一个可评估的 checkpoint，但只有 2 格的最高分超过底座，过完资格检查和安全回滚后**只剩 1 格**：Terra 指挥 4B 学数学，17.86 → 20.10。而且这条血统后来的后代从 20.10 跌到 2.78 再爬回 18.17——唯一的那次成功，方差大得随时会被自己吞掉。搜得最宽的 Sol 产出 33 个 checkpoint、烧 76.56 个 GPU 小时，一个超底座的都没有。还有个陷阱被点名：一条血统分数从 0.79 涨到 2.38，看起来在进步，其实离 17.86 的底座还差得远——那只是从自己训出的坑里往外爬。

**RQ3 外壳演化：最好的自生成外壳仍输给原版。** 运行时模型固定 Qwen3.5-4B，参考外壳是原版 Qwen-Agent，四个「创作者」各生成一个新外壳，冻结后在 20 道保密写作题上各跑三遍。结果：原版 28.64 分，GPT-5.6 Sol 做的最接近（27.22，差 1.42 分），Terra 20.76，Luna 19.32，Qwen3.5-4B 自己连一个能跑的都没做出来。三个失败案例很有教育意义：

- **Luna**：自验证从 7/8 改到 8/8 就收工（全程约 40 分钟）。它的改动让答案结构更完整，但把「解释这个公式/参数」这类直接问题统统重写成「这是个研究设计问题」——自己出的题满分，真考卷 19.32 分。
- **Terra**：正确删掉了一个会编造统计结果的审稿环节，却漏了一条输出完整性检查——计算器调用后如果模型响应为空，就把半截草稿交上去。就这两个任务，贡献了那次执行约 70% 的失分。
- **Sol**：搜了 3 小时 11 分，测试最全，也最保守——宁可要验证分更低的方案，也不要有幻觉、延迟、工具失控的方案。

总开销：带反馈协议 322.61 个训练 GPU 小时，盲考协议 149.24 个，外壳演化 0 个（不动权重）。

把三块拼起来看图景很清楚：模型「执行训练循环」的能力其实不差——30 格里 28 格都完整走完了「选数据 → 训练 → 出 checkpoint → 评测」，外壳演化也都能产出能跑的成品；掉链子的全在后半段：分数超不过底座、超过了留不住、外壳比不过现成的。这就是标题那句话：训练循环关上了，能力循环没有。

顺带一个对「自进化排行榜」有用的观察：论文里唯一那次成功（Terra 数学 +2.24 分），如果按常见做法报「最佳中间 checkpoint」，会显得更亮；按「两次独立 run 的平均」报就只剩一次 +2.67；按「过回滚闸的保留增益」报就只剩 30 分之 1。**同一批实验，三种口径，三种乐观程度**——这也是这篇 benchmark 论文真正想立的规矩。

## 别被结果骗了

**样本太小，别把「输给原版」当定律。** 外壳那 1.42 分的差距，是 20 道题、每个外壳跑三遍、没报告分数波动算出来的——这个量级基本是噪声。论文自己承认这些差异「只是描述性的」。唯一那次保留增益（+2.24 分）出现在 30 格里的 1 格，同一血统内部方差就有这么大。

**对照组不是严格对照。** RQ1 的 32.90 对 27.07 是官方成绩对论文复跑，作者明说这不是「只换提示词」的因果对比——官方系统可能底座、配置都不同。掉的那 6 分里有多少来自目标模糊、多少来自别的差异，拆不开。

**为什么底座会被训到 0 分，论文没解释。** 4B 科学推理从 44 分训到两次 0 分，这是最有技术含量的现象，但论文只拿它当「训练致回归」的证据用，没分析是数据烂、配方错还是灾难性遗忘。

**判卷的是另一个模型。** 520 道题用 gemini-3.5-flash 打分（10% 不确定就保守判负）。判分质量直接决定谁超底座谁不超，而论文没对这个裁判做独立校准。

**几个关键配置没写清楚。** 带反馈模式里查询总分的限额是多少、三个 GPT-5.6 外脑（Luna/Terra/Sol）到底差在哪，正文都没交代。想复现会卡在这些地方。

**「递归」其实没跑。** 协议里设计了「下一代决策模型可以换成训练出的后代」，但实验里没人真的这么做；外壳演化也明确只有一步（H1 到 H2 就停）。所以它测的是单步自进化，不是递归自进化。

**六个「目标」更像六个知识领域。** 科学推理、人文社科、健康医学……大半其实是知识问答。真正的能力型目标（比如「更会用工具」「写长文不跑题」）只占一两个，其中写作还只有 20 道题。所谓「把宽泛目标操作化」，很大程度上变成了「猜中考卷是知识问答型」——这个更难的问题论文没有碰。

## 如果我要用这个思路

1. **报告进度永远双对照：既对上一版，也对最初底座。** 只对上一版，会把「从自己搞坏的坑里爬出来」记成进步。这是全文最便宜也最该抄的一条纪律。
2. **把「安全回滚」写进实验协议，别做事后处理。** 开始前就声明：最终只保留超过底座的候选，否则回滚，平局规则也提前定死。事后挑规则永远偏向乐观。
3. **训练数据进流程前先过评测集重叠闸。** 精确加语义双重匹配，命中拒收。「隐藏评测」没有这道闸就是修辞。
4. **给模型语义动作接口，别给 shell。** 七类动作（注册/训练/验证/自评/评测/分支/终止）全部先验证后执行，拒绝的请求不留任何痕迹和分数。资源隔离、可审计、防白嫖查询一次全拿到。
5. **自建验证集先过多样性门槛。** 至少覆盖不同题型，验证分满格不构成停手条件——Luna 就是 1 道题 8 项清单满分就收工的反面教材。
6. **改外壳先写输出完整性不变式。** 「最终提交物非空且完整」这条硬检查的优先级高于任何花哨的审稿逻辑——Terra 70% 的失分就漏在这。
7. **隐藏评测实验要绑定配置指纹。** 实验身份 + prompt 版本 + SHA-256 哈希，启动和恢复时都校验，防止跑一半悄悄换成另一个设定。
8. **反馈通道定死语义。** 只有总分、有次数限额、失败的查询照样计数。防止模型把评测接口当训练信号刷，也防止靠故意失败重试白嫖查询。
9. **同一批实验用多口径报告。** 最佳中间分、终检平均分、过回滚闸的保留分，三个数都给。只报第一个的论文，乐观程度大约高一个量级。

## 名词小词典

| 术语 | 大白话解释 |
| --- | --- |
| vague goal（宽泛目标） | 只有方向没有考卷的目标：「提升数学推理」，不说考什么 |
| target operationalization（目标操作化） | 把宽泛目标翻译成具体学什么、拿什么数据、怎么验证——论文认为这是缺失的一环 |
| hidden eval（隐藏评测） | 520 道保密题，锁在控制器侧，模型永远看不到题目和答案 |
| proxy validation（代理验证） | 模型自己出题自己打分，天然偏向自己的长处 |
| harness（外壳） | 围绕模型的运行时提示词、工具策略、工作流、记忆、验证逻辑 |
| 底座（base model） | 起点 checkpoint，一切进步的真正参照物 |
| evaluated / eligible / selected / retained | 候选四层账：拿到分 → 合资格 → 被选中 → 过回滚闸真正保留 |
| rollback（回滚） | 选中候选不超过底座就退回底座，是协议内置动作不是补救 |
| aggregate-only feedback | 只给总分不给逐题反馈，且有查询次数限额 |
| 训练致回归 | 自己选的数据和配方把能力训坏；之后分数回升只是爬坑不是进步 |
| 决策模型（decision model） | 指挥搜索的模型，可以就是底座自己（Self），也可以是外脑（Luna/Terra/Sol） |
| campaign（战役） | 一次完整自进化实验：目标 + 保密评测 + 动作契约 + 预算 + 预声明的终局规则 |
| evolution round（演化轮） | 一段有界搜索：轮内决策模型固定，可以试多个候选再提交 |
| 决策模型外脑（Luna / Terra / Sol） | 三个 GPT-5.6 配置，替 Qwen 底座做训练决策（论文未说明三者具体差异） |
| settled GPU 小时 | 真正落地完成的训练算力账，不是预算上限也不是启动过的任务数 |
| Self 配置 | 底座模型自己当自己的决策模型——自己决定怎么训练自己 |
| fail-closed 判分 | 裁判不确定就保守判负（本文阈值 10%）：宁枉勿纵的打分策略 |
| task macro / example micro | 外壳评测的两种算法：题目等权 vs 被评分的答案等权，一道题可以出多个被评分的答案 |
| target operationalization 缺失 | 全文的问题定义：现有自进化研究都默认「该学什么」已有人回答 |
